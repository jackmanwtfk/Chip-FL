# 实验设计执行方案（对应 `/root/autodl-tmp/实验设计.md`）

## 固定前提

- 全局数据划分不变：`train=15, val=2, test=4`
- 联邦切分固定为：`LS+QS`（3 clients，`3/5/7`）
- 切分顺序：先联邦切分，再各 client 内子图切分

---

## 实验 1：最小闭环

1. `EXP1_local_lsqs`：Local Learning（3 个 client 各自训练，最后平均）
2. `EXP1_fedavg_lsqs`：FedAvg
3. `EXP1_fedprox_lsqs`：FedProx（`mu=0.001`）
4. `EXP1_fededa_lsqs`：FedEDA（`size + p`）

---

## 实验 2：元数据消融

1. `EXP2_baseline_none`：不加 FedEDA 正则
2. `EXP2_fededa_size`：FedEDA（`size only`）
3. `EXP2_fededa_p`：FedEDA（`p only`）

---

## 实验 3：Partition 消融

1. `EXP3_fededa_size_p_nopart`：`No partition`（`sub_graph_size=0`）+ FedEDA（`size+p`）
2. `EXP3_fededa_size_p_part`：`Partition`（`sub_graph_size=50000`）+ FedEDA（`size+p`）

---

## 配置与清单位置

- 配置目录：`configs/exp_design/`
- 清单文件：`configs/exp_design/manifest.json`
- 生成脚本：`scripts/generate_experiment_design_configs.py`
- 运行脚本：`scripts/run_experiment_design.sh`

---

## 运行命令

```bash
# 仅查看将要运行哪些 case
bash scripts/run_experiment_design.sh --group all --dry-run

# 只跑实验1
bash scripts/run_experiment_design.sh --group exp1

# 只跑实验2
bash scripts/run_experiment_design.sh --group exp2

# 只跑实验3
bash scripts/run_experiment_design.sh --group exp3

# 全部运行
bash scripts/run_experiment_design.sh --group all
```
